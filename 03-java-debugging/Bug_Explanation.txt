JAVA OOP BUG FIX EXPLANATION
=============================================

Project: StudentManager Bug Fix
Date: August 2026

---------------------------------------------
BUG #1: Constructor Missing Data Types
---------------------------------------------
PROBLEM:
public StudentManager(name, age, grade) {
    // Missing data types for parameters
}

EXPLANATION:
In Java, all parameters MUST have data types.
The compiler doesn't know what 'name', 'age', and 'grade' are.

FIX:
public StudentManager(String name, int age, double grade) {
    // Now Java knows: name is String, age is int, grade is double
}

---------------------------------------------
BUG #2: Missing Validation for Grade
---------------------------------------------
PROBLEM:
public void updateGrade(double newGrade) {
    studentGrade = newGrade; // No validation!
}

EXPLANATION:
A student can get a grade of 150 or -20, which is impossible.
This can cause logical errors in the program.

FIX:
public void updateGrade(double newGrade) {
    if (newGrade < 0 || newGrade > 100) {
        System.out.println("Error: Grade must be between 0 and 100");
        return;
    }
    studentGrade = newGrade;
}

---------------------------------------------
BUG #3: Missing Grade Validation in isPassing()
---------------------------------------------
PROBLEM:
if (studentGrade >= 75) {
    return true;
} else {
    return false;
}
// If grade is invalid (e.g., -10), it returns false, which is misleading.

EXPLANATION:
A negative grade shouldn't just return false. It should indicate an error.

FIX:
if (studentGrade < 0 || studentGrade > 100) {
    System.out.println("Warning: Invalid grade detected!");
    return false;
}
return studentGrade >= 75;

---------------------------------------------
BUG #4: Missing Return Type in displayInfo()
---------------------------------------------
PROBLEM:
public displayInfo() {
    // Missing void return type
}

EXPLANATION:
In Java, every method must specify a return type.
If a method doesn't return anything, use 'void'.

FIX:
public void displayInfo() {
    // Now Java knows this method returns nothing
}
